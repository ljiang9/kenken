# kenken 贤者之谜

终端里的 KenKen 数字谜题：n×n 拉丁方阵 + 笼子算术约束。纯标准库，零依赖。

## 玩法

- 每行每列都是 1..n（拉丁方阵）。
- 每个笼子有一个目标数和运算符（`+ - x /`，单格笼直接填数）。
- `-`/`/` 笼只含 2 格：两数之差/整除商等于目标。

## 用法

```bash
python3 -m kenken                  # 生成 4x4
python3 -m kenken --size 5 --seed 7
python3 -m kenken --solve          # 生成并求解
python3 -m kenken --show-solution  # 显示生成时的答案
python3 -m kenken --selftest       # 内置自检
```

## 真实验证记录

- `python3 -m py_compile kenken.py __main__.py`：通过。
- `--selftest`：3/3 通过——
  1. 手工 4x4 谜题（9 个笼子，含 `+-x`）求解结果合法；
  2. 20 个种子 × 4x4/5x5 生成的谜题全部可解、解合法（行列 1..n + 笼算术）；
  3. 矛盾笼子正确返回无解。
- 30 个种子 × 4x4/5x5：生成器的标准答案全部通过 `check_solution`。
- 5 种运算符（`+ - x / =`）在生成谜题中都出现过。
- `--size 5 --seed 7 --solve`：合法，62 个搜索节点。

## 设计取舍

- 生成方式：随机拉丁方阵 → 随机生长划分笼子 → 由笼内数字反推目标与运算符，保证"至少有一个解"。
- 求解：回溯 + 行列互异 + 笼约束剪枝，4x4/5x5 毫秒级。

## 已知局限

- 只支持 4x4/5x5 小棋盘；更大尺寸回溯会变慢。
- 生成的谜题**不保证唯一解**（只保证可解）；接受任何满足约束的解。
- 无交互式填涂，只有"看题+对答案"模式。
- 需要 Python 3.10+，终端中文显示正常即可。
